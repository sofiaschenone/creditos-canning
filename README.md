# Créditos Canning

Landing page profesional desarrollada para **Créditos Canning**, orientada a la captación de solicitudes de préstamos personales para jubilados, pensionados, fuerzas de seguridad, fuerzas armadas y docentes.

## Tecnologías Utilizadas
- **React 18** + **Vite** (Entorno de desarrollo rápido)
- **Tailwind CSS** (Diseño y estilos responsivos)
- Integración directa con canales de atención por **WhatsApp**.
